# u-ronigrv-a-day-of-one-line-pitches-12cd9bb3

This entry is a tiny Node program with one job: it writes a single
persuasive sentence to `/output/entry.txt`. The sentence speaks to
someone who has never coded, and it tries to be honest about what
they get — a working first version they can try and share, made
from a plain-words description of their idea.

## Run it

```sh
node main.ts
```

The program creates the output folder when it is missing, saves
the pitch, and prints how many characters it wrote. The pitch is
kept under the 240-character limit for the competition.
